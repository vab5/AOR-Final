## Project Overview

This project implements a Rapidly-exploring Random Tree (RRT) path planner for the **da Vinci Research Kit (dVRK)** Patient Side Manipulator (PSM) using **ROS 2** and the official dVRK software stack. The robot was tasked with drawing a capital **"V" shape** in its workspace while avoiding user-defined obstacles.

---

## Steps to run path planning:

### 1. Install dVRK ROS 2 Stack

Follow the official dVRK ROS 2 installation instructions:  
📄 https://dvrk.readthedocs.io/2.3.0/pages/software/compilation/ros2.html

Ensure the following:

- ROS 2 Humble is properly installed and sourced

### 2. Launch the Simulation

```bash
ros2 launch dvrk_model arm.launch.py generation:=Classic arm:=PSM1
```

This will launch two GUIs: Rviz (for visualization), and a QT interface (for user interaction).

### 3. Initialize the Robot

To initialize the virtual robot:

- Click “Home” → The “psm1” status bar should turn green.
- Click “PSM1”, then “Select Tool Type” to choose a random surgical instrument (e.g., Large Needle
  Driver).
- Click “Home” again → The instrument should move slightly downward and stop.
- Now, the robot is ready for control.

### 4. Execute the Path Planning

To execute our path planning algorithm:

- Copy and paste the code from the submitted python file into the dvrk_arm_test.py file in the dvrk workspace.
- Open another terminal.
- Source the dVRK workspace.
- Run:

```bash
ros2 run dvrk_python dvrk_arm_test.py
```

## Implementation Details

- **Starting Point:** Extended the official `dvrk_arm_test.py` with a custom RRT\* planner and motion executer inside the `drawV()` method.

- **Waypoint Definition:** Hardcoded a 3-point "V" trajectory in 3D space using real-world coordinates relavent to the dVRK's Cartesian workspace. These waypoints can be changed by modifying the `waypoints` variable assignment in the `rrt()` function.  
  Example:
  ```
  waypoints = [
                [0, 0, -0.1],
                [0.05, -0.05, -0.11],
                [0.1, 0.0, -0.12]
            ]
  ```
- **Obstacle Modeling:** Placed small spherical obstacles at calcuated midpoints between waypoints to test collision-aware planning.

- **RRT\* Path Planner:**
  - Extended `RRTStar` class to support:
    - 3D planning with a step size of 0.001
    - Goal region tolerance of 0.003 meters.
    - Increased bias sampling for faster converges.
    - Waypoint path planning.
  - **Execution:**
    - Full "V" path generated by connecting sub-paths between adjacent waypoints.
    - Each 3D point along the final path was visited using `move_cp()`
  - **Visualization:**
    - Plotted the trajectory, obstacles, and waypoints in 3D using Matplotlib.
    - Saved both path and plot to the `results/` directory:
      - `results/final_path.txt`
      - `results/final_path_plot.png`
